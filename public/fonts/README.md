# Self-hosted fonts

Poppins and Lora for Solvexo's own site and dashboards (`@font-face` rules in `index.html`), served from this
domain so the first page load does not wait on two extra connections to Google Fonts. Latin and Latin Extended
subsets only, as served by Google Fonts. Both families are licensed under the SIL Open Font License 1.1
(https://openfontlicense.org), which allows bundling them with a website.

Store themes' other font families still load from Google Fonts.
